# apply-with-ease — Agent Guide

## Stack

- **Runtime**: Bun (lockfile: `bun.lock`)
- **Framework**: TanStack Start (React 19) with SSR
- **Routing**: TanStack Router (file-based, auto-generated `src/routeTree.gen.ts`)
- **Data**: TanStack Query + Supabase (`@supabase/supabase-js`)
- **Styling**: TailwindCSS v4 + Radix UI (shadcn/ui, `components.json`)
- **Auth**: Custom Supabase auth (`src/lib/auth/`, `src/integrations/supabase/`)
- **Deploy**: Vercel — Nitro `vercel` preset (Build Output API → `.vercel/output/`)
- **Lint/Format**: ESLint + Prettier (`eslint.config.js`, `.prettierrc`)

## Commands

```bash
bun dev          # vite dev (SSR dev server, vercel-dev emulation)
bun build        # vite build (production, outputs to .vercel/output/)
bun build:dev    # vite build --mode development
bun lint         # eslint .
bun format       # prettier --write .
```

## Key Architecture

- **Server entry**: `src/server.ts` — wraps TanStack Start entry with custom SSR error handling (catches h3-swallowed errors)
- **Router**: `src/router.tsx` — creates router with `routeTree.gen.ts`, provides `QueryClient` via context
- **Routes**: File-based under `src/routes/` — admin panel at `/admin/*`, public at `/`, `/estoque`, `/login`, `/veiculos/$slug`
- **Path alias**: `@/*` → `src/*` (tsconfig + vite)
- **Supabase**: Client in `src/integrations/supabase/client.ts` (browser) and `client.server.ts` (server); types in `src/integrations/supabase/types.ts`
- **DB types**: `src/lib/db/types.ts` (app-level), `src/lib/db/store.ts` (state)
- **Auth service**: `src/lib/auth/auth-service.ts` + `admin-bootstrap.functions.ts`

## Env

- `.env` has `SUPABASE_*` and `VITE_SUPABASE_*` (both required; Vite injects `VITE_*` to client)
- Supabase project: `lhbjkdtwlmqucqoqjdyb`

## Gotchas

- **Do not edit** `src/routeTree.gen.ts` — auto-generated by TanStack Router plugin
- **Server-only code**: Use `.server.ts` suffix or `@tanstack/react-start/server-only` (ESLint blocks `server-only` pkg)
- **Build output**: `.vercel/output/` (Nitro `vercel` preset, runtime nodejs24.x). The Vite config in `vite.config.ts` is hand-written (no Lovable wrapper) and wires the `vercel` Nitro preset directly.
- **Supabase service role**: `src/integrations/supabase/client.server.ts` (used by `admin-bootstrap.functions.ts`) requires `SUPABASE_SERVICE_ROLE_KEY` as a server env var — configure it in Vercel.
- **Env**: `.env` is gitignored; configure `SUPABASE_*` / `VITE_SUPABASE_*` (+ `SUPABASE_SERVICE_ROLE_KEY`) as Vercel environment variables.
- **Bun config**: `bunfig.toml` enforces 24h supply-chain guard
